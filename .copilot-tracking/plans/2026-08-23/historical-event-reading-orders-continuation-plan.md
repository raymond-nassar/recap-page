## Executive Summary

Publish the earliest five unresolved entries in the maintained pre-Maximum Security timeline:
Reed Richards and Sue Storm's Wedding, Kree-Skrull War, The Night Gwen Stacy Died,
Avengers/Defenders War, and Thanos War. The batch adds 32 exact issues. Four candidates have no
current overlap; Kree-Skrull War is a centrally approved nine-issue subset of Essential Avengers.

Implementation will add a distinct continuation-batch authority instead of replacing the original
five-event contract. It will preserve source order in evidence, verified first-on-sale chronology in
the catalog, all inherited blockers, and every later candidate. Current main and all dependent
reports, digests, approvals, authoring, release evidence, checks, and browser observations must be
regenerated after any relevant source or catalog change.

### User-visible result

Timeline gains five older historical event guides from 1965 through 1974. Each card credits Comic
Book Reading Orders, links to the exact source surface, and contains the complete reviewed sequence.
Existing reading progress, availability behavior, reader launching, and saved lists do not change.

### What may not be obvious

* The source lists Thanos War after two later-starting 1973 stories, so the shelf must not copy source
  order as chronology.
* Kree-Skrull War is intentionally useful as a compact event route even though all nine issues are
  already present inside the much larger Essential Avengers guide.
* Timeline ranges are exact source rows. Their inclusive ascending expansion is deterministic and is
  not a substitute or inferred order.
* The original five-event release remains a separately validated historical batch.

### Unresolved decisions or blockers

None before critique. Any exact duplicate, missing metadata row, source digest change, unapproved
relationship, or stale evidence discovered later blocks the complete batch until centrally resolved.
The batch may not be shortened or substituted.

## Functional Requirements

1. A release selector must distinguish the original MRT-003 five from MRT-003-C02 batch 1 and reject
   unknown, incomplete, repeated, or mixed release IDs.
2. The maintained inventory must preserve all 58 source identities, the exclusive cutoff, alternate
   universes, retained terminal states, original five shipped states, and the continuation five as
   one complete release.
3. Each continuation packet must bind provider, source URL and optional timeline section, current
   source SHA-256, exact source boundary, exclusions, exact rows, manifest proposal, source review,
   and chronology anchor.
4. All 32 rows must resolve to exact current Marvel issue identities in source order. Manual series
   aliases require explicit central approval and rationale.
5. Each candidate must receive a report against the complete current library and all four selected
   peers. Exact duplicates have no approval path.
6. Kree-Skrull War's candidate-subset relationship to Essential Avengers must be approved by named
   central stronger-model authority. Every other current relationship must be `none`; any new
   non-none relationship blocks pending a central decision.
7. Approval and authoring must require all five continuation IDs in verified shelf-chronology order,
   while source packets and inventory retain source positions 1 through 5.
8. Authoring must publish five complete event checklists and mark only their inventory records
   shipped. Vendoring must generate five payloads and the current catalog without placeholders or
   unresolved rows.
9. Cards must use the Comic Book Reading Orders source origin, exact source link, null source
   licence, remote cover URLs only, original project descriptions, and no copied source presentation.
10. Release records must account for completion, retained blockers, and ranked remainder, then start
   the next batch automatically after merge.
