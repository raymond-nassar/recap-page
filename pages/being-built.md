# What's being built

These are the major features the owner has chosen to share, not the full planning board.
There are no promised release dates.

## Cloud backup

Keep a backup in your own cloud storage account. Backup is optional, not automatic device
sync: each installation saves separately, and restoring a backup replaces its saved data.

- **OneDrive:** automatic backup shipped in 4.3.0 on Windows and Android.
- **Google Drive:** work for Windows and Android is deferred while the owner hears from users.
  It has not shipped. See [the cloud backup request](https://github.com/raymond-nassar/recap-page/issues/810).
- **iCloud:** planned only for iPhone and iPad, not Windows or Android. The iOS app currently
  has no cloud backup. See [the iOS and iCloud request](https://github.com/raymond-nassar/recap-page/issues/949).

See [the release notes](https://github.com/raymond-nassar/recap-page/blob/main/CHANGELOG.md)
for delivered changes, or [help shape Recap Page](https://raymond-nassar.github.io/recap-page/#feedback).
