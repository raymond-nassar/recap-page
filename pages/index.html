Open Google Play About the Android app

  • Made for touch. Larger buttons, light and dark themes, compact filters, and easy-to-reach list options. Press Back to close menus.
  • Android's Read uses an installed browser, not the Marvel Unlimited app.
  • Move between devices. Desktop and Android save separately. Move progress with a JSON backup. Restoring replaces the app's saved data.

How it works on desktop

An example with made-up progress.

  1. Browse for a list. Add Civil War: Avengers and Aftermath Reading Order from Comic Book Herald's guide.
  2. See what's next. With the first six comics marked read, Civil War (2006) #7 is next.
  3. Choose Read. Until December 7, 2026, the Marvel Unlimited web reader opens in a separate tab when a link is recorded, with a comic details page as the fallback. From that date, Read opens the general Marvel Comics website, not a single-comic link.
  4. Mark it read. Return and choose Done. New Avengers (2004) #21 is next. Reading isn't detected automatically.
  5. Come back anytime. Reopen the list in the same browser profile to resume.

An issue marked read stays read across lists. Each list keeps its own order.
