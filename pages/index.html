Overview

A private companion for long Marvel reading journeys

Recap Page organizes curated reading lists, keeps your place issue by issue, and opens the official Marvel Unlimited reader. It includes no comics and does not replace a Marvel Unlimited subscription.

Get started

Run Recap Page on your computer

Always use this exact address

http://127.0.0.1:8787/

A different hostname or port uses separate browser storage and looks like a fresh app. Check the address before assuming that progress was lost.

Project questions

Optional answers from GitHub Copilot

The project guide opens a GitHub Copilot Space built from selected maintained public documents. All documentation and support routes remain available without Copilot.

Before you use the project guide

  • Copilot Free works. You need a GitHub account with Copilot access.
  • Your questions use your Copilot Chat allowance or AI credits.
  • The project does not pay for or meter your use.
  • GitHub sends your question and selected public project context to an AI model.
  • Chat messages are retained for 28 days.
  • Individual-plan interactions may be used to improve models unless you opt out in your GitHub Copilot settings.
  • Answers can be incomplete or wrong. Check the linked source before relying on one.
  • Do not paste reading progress, lists, notes, backups, personal information, or vulnerability details.

Recap Page sends nothing to this guide. GitHub Copilot is not maintainer support.
