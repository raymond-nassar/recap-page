                    Backup & settings

                    Your reading progress lives in this browser, at this exact address, and is never sent anywhere.

                    Data safety

                    Back up reading data

                    Reading-data backups contain lists, notes, issue ratings, read progress and deferrals.

                    For a complete reading and history transfer, download the reading-data and completion-history backups together, plus the separate import-draft file when a draft or retained draft source is present. Settings are not included. These are separate files, not interchangeable formats.

                    Restore from a backup

                    Restoring replaces all reading data after confirmation and keeps a saved copy of what it replaces. Undo is offered once in this tab. After Undo or reload, use the clearly named saved-copy action instead. Completion and enjoyment history are unchanged.

                    Separate import draft

                    Includes exact pasted source, source positions, selected matches and retained previous sources. No automatic expiry. Reading-data and completion-history backups do not include it. Restoring reading data keeps the draft but requires review before applying more comics.

                    Checklist and sharing options

                    Order-only Markdown excludes notes, descriptions, reading progress and availability overrides. Personal Markdown includes notes and read checkboxes, but notes do not re-import. JSON is the lossless reader-data backup.

                    Copies kept after a failed read

                    Recovery copies appear here only when saved data cannot be read.

                    Where these copies live

                    Those copies are kept until you remove them here, and they sit in the same browser storage as your lists and progress.

                    Cover art

                    How covers are requested

                    Covers load straight from Marvel's image servers. The metadata service reports each address, but one naming any other host is refused before a request is made. This app stores only the address, never the image itself, and never proxies or re-hosts artwork. Switch covers off and every cover becomes a plain typographic tile, and no cover is requested at all.

                    Theme

                    What the choice affects

                    The choice is stored in this browser alongside your other settings and is never sent anywhere. High contrast mode and reduced motion are still honoured whichever you pick.

                    Story summaries

                    On by default. Loading a summary still asks permission. Titles and covers may contain spoilers.

                    What this choice changes

                    Turn off to show already-fetched summaries without Show and Hide controls. This does not identify spoilers or filter titles and covers. Changing this choice resets individual reveal choices, not fetched text. The preference is saved in this browser, separately from progress and backups.

                    About this app

                    An unofficial fan project

                    Not made by, endorsed by, or affiliated with Marvel or The Walt Disney Company. Marvel, Marvel Unlimited, and all related names, characters, and logos are trademarks of Marvel Characters, Inc.

                    Metadata and links only

                    No comic content is stored, copied, proxied, or served. The app tracks which issues you have read and links out to Marvel's own site and reader. Reading an issue requires your own Marvel Unlimited subscription. Cover images load directly from Marvel's own servers, and an address on any other host is refused rather than requested. Switching cover art off stops them being requested.

                    Where the metadata comes from

                    Issue, series, and creator metadata comes from the community marvel.emreparker.com API, built from emreparker/marvel-comics and originating with Marvel. The snapshot ends in 2025, so very recent issues may be missing. You can still add those by hand. The API base URL is configurable under Backup & settings.

                    Reading List credits

                    Thank you to Comic Book Herald and Comic Book Reading Orders for the guides used to compile many bundled Reading Lists. Every externally guided list names and links to the exact source it follows. Reading Lists assembled in this project come from Marvel series metadata or are compiled by hand.

                    Your data

                    Everything you save lives in this browser, at this exact address: your lists, your reading progress and your notes. There is no account to create, and no analytics or tracking of any kind. Your progress and your notes are never sent anywhere. Clearing site data for this address erases them, so export a backup regularly.

                    What leaves this machine, request by request

                    What does leave this machine is the ordinary business of fetching what is on screen. Opening the app asks the metadata API named above whether it is reachable, which is what the status pill reports. Searching for issues sends what you typed, and so does asking an imported line to find its own match; searching the catalog, series or creators is answered from files already on this machine, but browsing a series or a creator's comics then asks the metadata API for the issues it lists. Selecting comics and choosing a list stays on this device. Filling in details sends every issue number still missing them, across every list you keep, starting with the one you are about to read. Cover art is requested from Marvel's image servers as it appears, so those servers see which issues are on screen; switching cover art off stops them being requested at all. Those are the only servers a cover is ever asked of: an address the metadata API reports on any other host is refused before anything is fetched. Pressing Read opens Marvel's reader at read.marvel.com when its direct reader link is known. With a matching issue-page link but a refused reader-ID lookup, Read opens the exact Marvel issue page on marvel.com directly. Otherwise the launch tab asks the metadata API for a missing reader link and opens Marvel's reader if found, or the issue page if not. Adding an issue by hand sends the words in the title box to the Marvel Fandom wiki only when you press the lookup button; the wiki sees that title, but no picture is fetched. These requests include no part of your lists, progress, or notes.
