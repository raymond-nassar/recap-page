# Amazing Spider-Man: Issue-by-Issue Reading Checklist

Compiled by hand for this project from Comic Book Herald’s complete Amazing Spider-Man guide, read as a reference and re-expressed here. It is not derived from Marvel metadata and cannot be checked against it; only the issue ids and titles come from Marvel, by resolving each issue the guide names. The checklist follows the guide’s own chronological section order from Amazing Fantasy #15 through its most recent entries.

The guide’s own highlighted-edition callouts and a handful of redundant restatements of ranges already listed are not repeated; where the guide gives both a coarse trade summary and a precise issue-by-issue breakout for the same stretch (the 2019 .HU annual tie-ins and the 2021-2022 Beyond arc), the precise breakout is kept and the coarse summary is dropped so the checklist is not duplicated out of sequence.

A row with no link is a reference the guide names that this project could not resolve to a single Marvel-metadata issue: a product that is not a discrete comic (a wall calendar, a text recap page), a story credited without an issue number, or an issue the metadata service itself does not carry. None are invented. See [issue #248](https://github.com/raymond-nassar/recap-page/issues/248) for the full list of what could not be resolved and why.

See [the data provenance record](../../../docs/DATA_PROVENANCE.md) for the permission boundary and review method.
