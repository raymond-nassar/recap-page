# The Defenders: Issue-by-Issue Reading Checklist

Generated for this project by scripts/author-cbh-packet.mjs from the reviewed and frozen the-defenders-reading-order issue mapping.

The frozen source records 331 issue occurrences, including 12 intentional repeats; this checklist lists each distinct comic once at its first source occurrence.
No source commentary or images are copied. Issue identities, titles, and exact links come from Marvel metadata or reviewed official Marvel issue pages after the packet resolution and overlap gates passed.
See [the data provenance record](../../../docs/DATA_PROVENANCE.md) for the permission boundary and review method.
