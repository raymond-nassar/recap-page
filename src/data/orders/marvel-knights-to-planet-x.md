# Marvel Knights to Planet X: Issue-by-Issue Reading Checklist

Compiled by hand for this project from owner-curated source positions recorded in GitHub issue #276. The original group boundaries stay as visible section headings, and each quoted source row below preserves the source order and arc label before its expanded issue sequence.

It is not derived from Marvel metadata. The maintained metadata mirror resolves the issue ids, but the sequence itself is fixed here so the same owner-supplied guide can ship with explicit provenance and no inferred reordering.

See [the data provenance record](../../../docs/DATA_PROVENANCE.md) for the publication boundary this checklist stays within.
