# Setup to Modern Timeline

A hand-authored orientation path through Marvels and Sentry stories before the Modern Timeline begins. It is compiled from the owner-approved issue plan, not from scraped publisher pages, and the checklist keeps the five reader-visible section labels intact so the vendor pipeline preserves them as sections in the generated data.
