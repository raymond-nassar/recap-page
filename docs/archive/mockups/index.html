Five directions

Same data, same features, five different personalities. Open each one, click around a bit, then tell me a number. You can also mix: “number 2, but the dense list from 1” is a perfectly good answer.

Direction 5 · proposed

Longbox Focus, the hybrid

Focus's calm single-column flow and fact row, wrapped in Longbox's cover-forward atmosphere and left rail. One confident “read this next” card over its own blurred artwork, a “coming up” shelf, and the full 219-issue list collapsed until you want it. Includes a working cover art on/off toggle so you can see the typographic fallback.

Start here. This is what I propose building.

 Direction 1

Longbox

Dark, dense, cover-forward. A media library for comics, closest to Plex or Letterboxd. Covers do the navigating.

Best if you want to browse and feel the collection.

 Direction 2

Continuity

A vertical spine you read down, with covers as stops along the way. Order is the visual metaphor, because order is the whole point.

Best if the reading order is what you care about most.

 Direction 3

Focus

One giant “read this next” card and almost nothing else. The list is there when you want it, hidden when you don't.

Best if you just want to be told what to read next.

 Direction 4

Command

Keyboard-first and information-dense. A table you can fly through, with a ⌘K palette for everything. No mouse required.

Best if you want speed and control over atmosphere.

What's real in these mockups

Everything on screen is real data: real issues from the Hickman → Secret Wars order, real cover art from Marvel's CDN, real dates. The buttons are decorative. I have not wired the logic in yet, and I would rather build it once against a design you actually like.

One thing I got wrong earlier

My research notes said the API had no cover art. That was true of the list endpoints but wrong for /v1/issues/{id}, which returns covers, descriptions, page counts and credits. That is why these mockups can lean on artwork, which is worth knowing because it was one of the main constraints on how this could look.
